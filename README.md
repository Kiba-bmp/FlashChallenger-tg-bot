# FlashChallenger

Telegram-бот, который выдает компании друзей готовое задание на реальное действие, запускает таймер и собирает отметки о выполнении

Проведите время со своими друзьями весело!

## Статус

Итерация 1 (v0.1). Таймер, кнопка "Выполнил" и счетчик - в следующих итерациях

## Что сделано сейчас

- Бот в личном и групповом чате по команде /challenge выдает случайное задание из базовой категории
- Задания не повторяются, пока не будут показаны все задания базы
- Банк из 50 заданий

## Запуск локально

1. Создать бота в @BotFather и получить токен
2. Склонировать репозиторий и перейти в его папку:
```
   git clone git@github.com:Kiba-bmp/FlashChallenger-tg-bot.git
   cd FlashChallenger
```
3. Создать виртуальное окружение и установить зависимости:
```
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
```
4. Создать файл `.env` с токеном:
```
   BOT_TOKEN=токен
```
5. Заполнить базу заданиями (один раз):
```
   python seed.py
```
6. Запустить бота:
```
   python main.py
```

После запуска бот отвечает на `/challenge` в личном чате и в группе, пока `main.py` работает

## Проектирование

- Python, aiogram 3
- SQLite, таблица challenges (id, text, category)
- db.py - работа с базой, seed.py - наполнение, main.py - команды бота
